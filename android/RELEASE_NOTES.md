豆奶签到 Android 1.0.0：手机应用内登录豆奶站点，设置北京时间的每日自动签到时间；支持 Bark 和 SMTP 邮件通知，验证码支持 SVG 算式与 PNG 图片 OCR。

安装后在首页填写站点的 HTTPS 根地址，打开签到页并完成网页登录。进入“自动签到设置”勾选每天自动签到，按需填写 Bark Key 或邮件配置并保存。也可以手动点“立即签到一次”。

APK 支持 Android 7.0 及以上的 ARM64 与 ARMv7 手机。Android 省电、断网和关机可能使定时任务延迟。此版本使用 GitHub Actions 的自动调试签名，可直接安装；后续若换用另一签名，更新时需要先卸载旧版。
