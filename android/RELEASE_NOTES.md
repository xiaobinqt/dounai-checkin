豆奶签到 Android 1.0.1：修复手机 WebView 密码栏连续输入时字符被覆盖的问题，并在顶部显示实际输入的密码字符数。网站以全屏模式打开，邮箱、密码和算式验证码都在网站原页面输入并提交；APK 不保存登录密码。

首次使用在首页填写站点的 HTTPS 根地址，点击“打开签到页”，在站点原页面填写邮箱、密码和算式验证码并完成登录。返回应用后，在“自动签到设置”勾选每天自动签到，按需填写 Bark Key 或邮件配置并保存。也可以手动点“立即签到一次”。

开启每日自动签到后，手机会在联网时约每 3 小时访问 `/user`，接收服务端更新的 Cookie。服务端明确判定登录态失效时只发一次 Bark 提醒；临时断网不会触发失效通知。省电、断网或关机可能延迟后台任务；服务端也可能不延长会话，因此仍有可能需要重新登录。

APK 支持 Android 7.0 及以上的 ARM64 与 ARMv7 手机。此版本使用 GitHub Actions 的自动调试签名，可直接安装。由于 v1.0.0 和 v1.0.1 的调试签名不同，从 v1.0.0 升级需先卸载旧版再安装；卸载会清除旧版的 Cookie 和通知配置。
