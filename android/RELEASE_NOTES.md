豆奶签到 Android 1.0.4 改善黑屏状态下的自动签到。部分手机熄屏后会暂时挂起 Wi-Fi，系统仍显示网络已连接，但实际 HTTPS 和 DNS 请求会失败。自动任务现在会在尚未提交签到时等待网络恢复，并按 15、30、60 分钟的间隔重试；进入签到提交阶段后不会自动重试，避免重复提交。

PNG 验证码只有一个完整且没有冲突的分栏识别结果时，现在允许使用该结果，改善细减号或浅色数字只在一种图像处理方式下识别完整的问题。

APK 支持 Android 7.0 及以上的 ARM64 与 ARMv7 手机，可以直接安装。若覆盖安装时提示签名不一致，需要先卸载旧版；卸载会清除 Cookie 和通知配置。
