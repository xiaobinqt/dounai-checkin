豆奶签到 Android 1.0.12 增强后台诊断：增加开机次数、距开机时间、进程 ID、省电和后台限制、精确闹钟权限与系统任务数量。打开应用时先采集状态再恢复闹钟；异步记录 WorkManager 任务状态，另记录请求阶段、HTTP 状态、失败类别、任务等待及停止事件。日志容量提高到 512 KiB，不记录服务端响应原文或凭据。任务状态异步采集，可稍后点击“刷新”查看。

PNG 识别失败时，应用会在自身私有目录覆盖保存最后一张失败图片和候选摘要，方便后续扩充回归样本；这些诊断内容不包含 Cookie、登录密码或通知凭据。每个签到任务仍最多补试一次，第二次失败后停止。

每日签到继续同时使用 WorkManager 和系统唤醒闹钟，重启、应用升级或系统时间变化后会尝试恢复计划。应用被强停期间无法记录事件，部分华为/EMUI 手机仍需重启解锁后打开一次应用。此次更新不改变签到策略，也不保证自动恢复或识别停止来源。

华为等后台管理较严格的手机，请关闭“自动管理”，同时允许“自动启动、关联启动、后台活动”，并关闭针对本应用的电池优化。设置完成后重新打开一次应用；在系统设置中“强行停止”后也需要重新打开应用。

APK 支持 Android 7.0 及以上的 ARM64 与 ARMv7 手机，可以直接安装。若覆盖安装时提示签名不一致，需要先卸载旧版；卸载会清除 Cookie 和通知配置。
